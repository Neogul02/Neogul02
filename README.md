## Quick Start

Just run the `neogul02` CLI like this:
```
npx neogul02
```
```
Options:
  -g, --github     open github
  -b, --blog       open blog
  -p, --portfolio  open portfolio (resume)
  -r, --resume     open resume (same as --portfolio)
  -c, --choichoi   open choichoi - PopupStore POS & ERP
  -t, --todolight  open todolight - Team ToDo & Calendar
  -e, --email      display email
  -v, --version    show version
  -h, --help       display help for command
```
